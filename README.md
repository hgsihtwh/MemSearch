# MemSearch

Интеллектуальная система семантического поиска и структурирования пользовательского видеоконтента короткого формата.

## О проекте

MemSearch - веб-сервис для поиска ранее сохраненных коротких видео по смыслу их содержания и автоматического структурирования пользовательской коллекции.

Система позволяет выполнять поиск по произвольному текстовому запросу на естественном языке на основе распознанной речи, названия и описания видео.

## Структура репозитория

- `backend/` - серверная часть приложения;
- `frontend/`- веб-клиент;
- `ml/` - компоненты машинного обучения;
- `docs/` - проектная и техническая документация.

## Разработка

### Ветвление

В проекте используется GitHub Flow.

Основная ветка `main` содержит актуальную стабильную версию проекта. Разработка ведется в отдельных ветках, создаваемых от `main`.

Для именования веток используется формат:

`<тип>/<краткое-название>`

Например:

- `feature/semantic-search`
- `feature/video-upload`
- `fix/search-ranking`
- `docs/technology-stack`

После завершения работы создается Pull Request в `main`. После проверки изменений ветка объединяется с `main` и удаляется.

### Коммиты

Для сообщений коммитов используется соглашение Conventional Commits:

`<тип>: <описание>`

Основные типы:

- `feat` - добавление новой функциональности;
- `fix` - исправление ошибки;
- `docs` - изменение документации;
- `test` - добавление или изменение тестов;
- `refactor` - изменение кода без изменения его поведения;
- `chore` - технические и вспомогательные изменения.

Описание коммита пишется на русском языке в прошедшем времени и отвечает на вопрос «что было сделано?».

Примеры:

`feat: добавлен семантический поиск`

`fix: исправлена обработка пустого транскрипта`

`docs: добавлено архитектурное решение по выбору стека`

`chore: настроено окружение разработки`
