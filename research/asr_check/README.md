# Проверка ASR на 10 клипах (MEM-16, 15.10.2026)

- `asr_check.ipynb` — Colab-ноутбук: скачивает аудио 10 клипов (yt-dlp), распознаёт faster-whisper **large-v3** и **small** (GPU T4, float16, VAD, beam 5), меряет время.
- `results/` — выгрузка ноутбука: `transcripts/NN_<модель>.txt` (фразы с таймкодами), `results.csv`, `results.json`.
- `asr_check_grading.xlsx` — ручная оценка (2 — смысл понятен полностью, 1 — частично, 0 — нет), по листу на клип; сводка и вывод.
- `make_grading.py` — сборка таблицы оценки из `results/`.

Клипы (№ в паспорте коллекции): TikTok 1, 20, 22, 31, 54, 66; VK 77, 85, 89, 91 — разный звук (хорошее, среднее, речь на фоне музыки, стендап, плохие вставки).

## Итоги

| | large-v3 | small |
|---|---|---|
| Оценка «2» (смысл понятен полностью) | 8 из 8 | 8 из 8 |
| RTF на T4 (время / длительность) | 0,13 (минута ≈ 8 с) | 0,05 (минута ≈ 3 с) |
| Ошибки | «теракт 25» вместо Therac-25 | «кот» вместо «код», «поцветы» вместо «пациенты», «спорт» вместо «спор», «мне» вместо «вне» |

- №31 — речи нет (исправлено в паспорте).
- №66 — речь поверх музыки, **обе модели вернули пустой транскрипт**: фильтр тишины VAD принял голос на фоне музыки за тишину.
- №54 (стендап) — large-v3 оставила только главного говорящего, выкрики из зала выкинула; small ловит реплики второго человека, но с ошибками.
- №89 — вставки с очень плохим звуком (их и человек разбирает с трудом) распознаны приемлемо.
- large-v3 лучше с английскими словами и терминами (Enter).

**Решение.** Основная модель — faster-whisper large-v3 на GPU; small — запасной вариант для сервера без GPU; GigaAM не нужен. В конвейере (MEM-30): ослабить порог VAD и, если транскрипт пустой, повторять распознавание без VAD.
