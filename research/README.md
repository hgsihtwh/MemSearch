# Исследования и эксперименты

Данные и ноутбуки, на которых выбирались модели и проверялось качество поиска. Код продукта здесь не хранится.

| Каталог | Задача | Что внутри |
|---|---|---|
| `collection/` | MEM-23, MEM-77 | Паспорт демонстрационной коллекции: 91 ролик TikTok и VK, речь, язык, текст в кадре, тема, качество звука |
| `download/` | MEM-20 | Скрипт пакетной загрузки коллекции через yt-dlp и ffmpeg (WAV 16 кГц и метаданные clip), сводка прогона: скачано 88 из 91, TikTok с российского IP работает, готовых субтитров нет |
| `queries/` | MEM-17 | 110 контрольных запросов с правильными роликами для Recall@10 и MRR |
| `asr_check/` | MEM-16 | Проверка распознавания речи faster-whisper large-v3 и small на 10 роликах, ручная оценка |
| `embeddings_check/` | MEM-76 | Сравнение multilingual-e5-large и BGE-M3, разбиения на фрагменты и реранкера; транскрипты 88 роликов |
| `pgvector_bench/` | MEM-78 | Замер pgvector и индекса HNSW на синтетических векторах 768 и 1024: время поиска топ-10, объём индекса, recall@10; запуск одной командой |

Ноутбуки запускаются в Google Colab на GPU (T4); замер `pgvector_bench/` — локально на PostgreSQL из `compose.yaml`. Решения по итогам экспериментов — в [docs/decisions.md](../docs/decisions.md).

Результаты `pgvector_bench/results.csv` и `results.md` сохранены как исторические данные: в них есть противоречия между вариантами `ef_search`, а соответствие сохранённого прогона текущей версии скрипта не установлено. Перед использованием результатов для выбора параметров требуется повторный замер и проверка планов запросов.
