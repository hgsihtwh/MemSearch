# Контрольные запросы (MEM-17)

Набор запросов с заранее известными правильными ответами для оценки качества поиска (Recall@10, MRR — MEM-39, MEM-55).

- `control_queries.xlsx` — запросы, лист «Сводка» со статистикой; столбец «Проверено» заполняется вручную после просмотра ролика.
- `control_queries.csv` — то же для скрипта оценки.
- `make_queries.py` — собирает оба файла; правильные ответы — номера роликов из `../collection/passport.csv`.

Все запросы сформулированы своими словами, без цитат из транскриптов и подписей. Виды запросов: «перефраз» (один правильный ролик), «тема» (несколько правильных роликов), «без ответа» (в коллекции нет подходящего ролика; в Recall не учитываются).

Запросы с основанием «транскрипт» сверены с распознанной речью (MEM-16); остальные составлены по подписям и комментариям паспорта и требуют просмотра ролика.

Запросы Анастасии, написанные после просмотра роликов, лежат в `make_queries.py` в словаре `MANUAL` (столбец «Автор запроса» = Анастасия). Правки вносить в скрипт и пересобирать: ручные правки в xlsx при пересборке затираются.
