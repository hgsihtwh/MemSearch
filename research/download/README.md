# Пакетная загрузка коллекции (MEM-20)

`download.py` берёт список ссылок TikTok и VK, через yt-dlp получает метаданные и звук, через ffmpeg сохраняет звук в WAV 16 кГц моно. Метаданные пишутся в формате [clip](../../docs/data-format/schemas/clip.schema.json). Если ролик недоступен, ошибка записывается в лог, а прогон продолжается.

## Запуск

Зависимости ставятся в отдельное окружение, не в проект:

```bash
python -m venv dlenv
dlenv/Scripts/python -m pip install yt-dlp curl_cffi imageio-ffmpeg
dlenv/Scripts/python research/download/download.py \
    --input research/collection/passport.csv --out D:/memsearch_dl --workers 4
```

- `--input` — паспорт коллекции (CSV с колонками «№» и «Ссылка») или txt-файл со ссылками, по одной в строке. Во втором случае `clip_id` — номер строки.
- `--out` — каталог результата. Его нужно указывать вне репозитория: по проекту видео и аудио не хранятся.
- `--proxy URL` или переменная окружения `MEMSEARCH_PROXY` — прокси для yt-dlp, например `socks5://127.0.0.1:1080`.
- `--cookies cookies.txt` — cookies в формате Netscape для роликов, которые требуют входа.
- `--workers N` — сколько роликов загружать параллельно. `--limit N` — обработать только первые N, `--only tiktok|vk` — только одну платформу, `--no-subs` — не сохранять субтитры.
- ffmpeg берётся из PATH, а если его там нет — из пакета imageio-ffmpeg.
- **curl_cffi обязателен для TikTok.** Без него yt-dlp не может имитировать браузер, и каждый ролик падает с ошибкой `Unexpected response from webpage request`.
- При повторном запуске уже скачанные ролики пропускаются, заново пробуются только упавшие.

## Что на выходе

| Путь | Что там |
|---|---|
| `audio/{clip_id}.wav` | Звук: PCM 16 бит, 16 кГц, моно. Временный файл, удаляется после распознавания |
| `clips/{clip_id}.json` | Ролик строго по схеме clip: платформа, внешний ID, автор, подпись, длительность, превью, статус (`transcribing` или `error`) |
| `meta/{clip_id}.json` | Поля, которых нет в схеме: название, описание, дата публикации, ссылка на превью, языки субтитров, выбранный формат |
| `thumbnails/{clip_id}.jpg` | Превью шириной 320 px |
| `subs/{clip_id}.{lang}.{ext}` | Готовые субтитры платформы, если они есть |
| `errors.log` | Недоступные ролики и точный текст ошибки |
| `report.csv` | Сводка по роликам: `clip_id`, платформа, статус ok/error, длительность, есть ли субтитры и на каких языках, ошибка |

В репозиторий добавлены только [`results/report.csv`](results/report.csv) и [`results/clips/`](results/clips/), без аудио.

## Результаты прогона по коллекции

Прогон 29.10.2026 из Красноярска, с российского IP и без прокси. Использовались yt-dlp 2026.10.26 и curl_cffi, 4 потока. Вся коллекция загрузилась за 7,7 мин и дала 102,6 мин звука (190 МБ WAV).

| Платформа | Скачано | Недоступны | С готовыми субтитрами |
|---|---|---|---|
| TikTok | 72 из 75 (96%) | №30, №55, №56 | 0 из 72 (0%) |
| VK | 16 из 16 (100%) | — | 0 из 16 (0%) |
| Всего | 88 из 91 | 3 | 0 |

**TikTok с российского IP работает, прокси в целом не нужен.** Нужен только curl_cffi (см. выше). Три ролика не скачались:

- №55 и №56 — `Your IP address is blocked from accessing this post`. Эти ролики закрыты для российского IP, их можно скачать через `--proxy` или `MEMSEARCH_PROXY` с зарубежным выходом.
- №30 — `This post may not be comfortable for some audiences. Log in for access`. Ролик доступен только после входа, ему нужен `--cookies` с cookies вошедшего аккаунта. Прокси здесь не поможет.

**Готовых субтитров yt-dlp не отдаёт ни для одного ролика.** Ни у TikTok, ни у VK нет ни `subtitles`, ни `automatic_captions`. У TikTok в данных страницы стоит `enableAutoCaption: true`, но список `captionInfos` пустой (`noCaptionReason: 4`), то есть без входа платформа автосубтитры не отдаёт. У VK-клипов субтитров нет совсем, и это совпадает с паспортом коллекции. Поэтому быстрого прохода «взять готовые субтитры вместо распознавания» не получится: распознавать нужно все 88 роликов.

## Рекомендации

- Для загрузки TikTok ставить yt-dlp вместе с curl_cffi (`yt-dlp[default,curl-cffi]`) и регулярно обновлять yt-dlp, потому что TikTok часто меняет страницы.
- Прокси держать как запасной вариант для отдельных роликов, закрытых по региону (около 3% коллекции). В рабочей системе его можно задать через переменную `MEMSEARCH_PROXY`.
- Ролики 18+ при анонимной загрузке не скачиваются. Для коллекции их можно добавить через `--cookies`, в продукте нужно показывать пользователю понятную ошибку.
- Быстрого прохода по готовым субтитрам нет. Быстро можно обработать только подпись ролика (`caption`), а звук всё равно нужно распознавать (faster-whisper large-v3, MEM-16).
- Звук TikTok берётся из дорожки самого видео, а не из формата `audio`: в TikTok это звук-трек, часто чужая музыка без голоса.
