# Паспорт коллекции (MEM-23, MEM-77)

`passport.xlsx` и `passport.csv` — 91 ролик демонстрационной коллекции: 75 из «Избранного» TikTok и 16 из VK. Для каждого ролика: платформа, ссылка, автор, подпись, доступность, наличие речи и текста в кадре, язык, тема, качество звука. Номер ролика (`№`) используется как правильный ответ в контрольных запросах и как `clip_id` в примерах формата данных.

`passport.py` собирает паспорт из файлов `links_*.txt` (ссылки в любом виде) и метаданных TikTok oEmbed и yt-dlp, сохраняя ручную разметку. Исходные списки ссылок в репозиторий не добавлены: это личные списки сохранённых роликов участников. Ролики собственного авторства участников из коллекции исключены.
