# REST API (MEM-27)

Спецификация — [`openapi.yaml`](openapi.yaml) (OpenAPI 3.1). Префикс всех путей — `/api/v1`. Просмотр: вставить файл в <https://editor.swagger.io> или открыть `/docs` запущенного backend (после реализации эндпоинтов).

## Доступ

Учётных записей нет (ФТ-7.5 в бэклоге). `POST /collections` создаёт коллекцию и один раз возвращает ключ; клиент хранит ключ на устройстве и передаёт его в `Authorization: Bearer <ключ>`. Telegram-бот получает ключ коллекции при привязке по одноразовому коду (`/telegram/link-code` → `/telegram/link`). Подробнее — [архитектура, раздел 6](../architecture.md#6-безопасность-и-приватность).

## Формат поиска

Запрос — `{"q": "…", "topic_id": 3, "limit": 20}`. Ответ — ролики целиком, один ролик — одна карточка (решение 11), упорядочены по лучшему фрагменту. В каждой карточке `match` — «почему найден»: источник (`speech`, `caption`, `title`, `ocr`, `scene`), цитата до 100 символов и диапазоны слов запроса для подсветки. Пустой `items` и `suggestions` — экран «Ничего не нашли». `query_id` связывает оценки «подходит / не подходит» с запросом. Модель и разбиение — решение 14: multilingual-e5-large, окно 15 с, шаг 7 с, гибрид с полнотекстовым поиском.
