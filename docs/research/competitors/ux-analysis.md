## Выводы по приложениям

### Recall
- 🟢 Карточка с вкладками «Заметки / Чат / Транскрипт»: краткое содержание и транскрипт с таймкодами на русском. Берём карточку с описанием и фрагментом речи.
- 🟢 Крупная кнопка «Открыть в TikTok».
- 🟢 Поиск находит русские слова. Пустая выдача предлагает «Искать с ИИ» и «Очистить поиск».
- 🟣 Экран «вставьте до 10 ссылок» перегружен. У нас одно поле и примеры TikTok и VK.
- 🟣 Сортировка, группировка и три вида отображения избыточны для телефона. Оставляем «сначала новые / старые» и сетку или список.
- 🟠 Дерево тегов; онбординг-видео.
- 🔴 Чат с базой, тесты, интервальное повторение, граф. Статусы «Summarizing…» без прогресса.

### mymind
- 🟢 Лист добавления из крупных карточек и подсказка про «Поделиться». Берём лист из 2–3 действий: ссылка, «Поделиться», перенос «Избранного».
- 🟢 Поиск внизу под большой палец, подсказки тегов при вводе.
- 🟢 Карточка: TL;DR, редактируемые теги, заметка.
- 🟣 Сетка без подписей. Для видео нужны название и совпавший фрагмент.
- 🟠 Serendipity — случайные старые сохранения.
- 🔴 Нет транскриптов, только английский, платный ИИ, пустая главная без подсказки.

### Sorti
- 🟢 Онбординг объясняет ценность и учит закреплять приложение в «Поделиться».
- 🟢 Простое модальное окно «Add with AI / manually» и «Add link».
- 🟢 «Open Original», текст из кадра (русские надписи OCR распознал), теги.
- 🟣 Для русского ролика только «A young woman talking to the camera»: речь не распознаётся. Приложение сырое (ручная проверка 10.10).
- 🟣 Категории создаются вручную. У нас темы появляются автоматически, их можно переименовать.
- 🟠 Выбор темы оформления, Siri, напоминания.
- 🔴 10+ экранов онбординга с опросами; поля «место», «дата», «голосовая заметка».

### Cosmos
- 🟢 Понимает русский запрос, ищет по визуальному смыслу — референс для поиска по изображению.
- 🟢 Плавающая нижняя панель с поиском, крупная сетка, «удерживайте, чтобы сохранить».
- 🟢 Скелетоны во время загрузки.
- 🟣 Выбор интересов в онбординге. У нас вместо этого сразу предложить перенос «Избранного».
- 🟠 Вкладки выдачи «Elements / Products / Collections».
- 🔴 Лента рекомендаций «For you».

### TapFold
- 🟢 Онбординг из 4 экранов, по одной мысли на экран, и тренировочное сохранение.
- 🟢 Нижняя навигация. У нас 3–4 вкладки: Поиск, Темы, Добавить, Профиль.
- 🟢 Режимы поиска «Keyword / Ask». У нас один поиск с подсказкой «опишите ролик своими словами».
- 🟣 Режим Ask по-русски ничего не находит, описания на английском.
- 🟠 Еженедельный дайджест; фильтры «Unread / All / Favorites».
- 🔴 «Upgrade to Pro» в профиле.

### Twelve Labs (десктоп, API)
- 🟢 Поиск момента в видео: сетка фрагментов с превью кадра и таймкодом — эталон выдачи поиска по изображению.
- 🟢 Видно, по чему совпало: изображение, аудио или транскрипт. У нас — речь, текст в кадре или кадр.
- 🟠 Анализ ролика по запросу, сегменты с таймкодами.
- 🔴 Интерфейс для разработчиков, английский, запрещён для России условиями.

## Что берём в наш UX (вход для MEM-24 user flow и MEM-25 вайрфреймов)

1. Онбординг ≤ 4 экранов. Последний — тренировка «Поделиться» или перенос «Избранного» расширением.
2. Нижняя навигация 3–4 вкладки, поиск внизу под большой палец.
3. Добавление — лист из 2–3 крупных действий плюс одно поле для одной или нескольких ссылок.
4. Карточка в выдаче: превью, название, краткое описание, совпавший фрагмент с таймкодом, отметка «найдено по речи / тексту в кадре / кадру», кнопка «Открыть в TikTok / VK».
5. Пустая выдача с подсказкой переформулировать запрос. Скелетоны при загрузке. Прогресс «обработано N из M».
6. Темы появляются автоматически, их можно переименовать. Ручных категорий нет.
7. Не делаем: чат с базой, тесты, граф, ленту рекомендаций, опросы в онбординге, платные стены.

Ключевые решения:
- **Онбординг:** 3–4 экрана (ценность → «Поделиться»/бот → первое действие), «Пропустить», без опросов и выбора интересов.
- **Добавление:** шторка из 2–3 действий, поле ссылок с фокусом, иконки TikTok/VK, сразу статус обработки.
- **Поиск:** один режим, строка внизу, выдача списком с совпавшим фрагментом, таймкодом и пометкой «найдено: речь / текст в кадре / кадр», советы при пустой выдаче.
- **Карточка:** «Открыть в TikTok/VK», описание, «Найдено по», свёрнутые транскрипт и OCR, редактируемые теги, одна страница вместо вкладок.
- **Главная:** главная = поиск плюс темы и недавние, прогресс «обработано N из M», навигация с подписями, пустое состояние с двумя действиями.

Ключевые решения:
- **Первый вход:** главная кнопка «Установить расширение», чек-лист из 3 шагов (расширение → перенос → первый поиск), блок о приватности, без анкеты.
- **Перенос:** кнопка расширения на странице «Избранное» TikTok, выбор объёма, прогресс в углу «Перенесено N из M», можно закрыть вкладку. Окно «Добавить» — список ссылок и плашка про расширение.
- **Поиск:** сетка в 3–4 колонки (превью, таймкод, ключевые кадры, совпавшая фраза), счётчик, «/» для поиска, чипсы тем, транскрипт фрагмента по кнопке.
- **Карточка:** боковая панель поверх выдачи; «Совпадения в ролике: N» с фрагментами; описание, теги, свёрнутые транскрипт и текст в кадре.
- **Главная:** поиск по центру, темы, недавние; сайдбар с подписями; горячие клавиши; вид «таблица» для больших коллекций (опционально).

## Поиск по образцу Twelve Labs (Figma, секция `31:1182`)

Twelve Labs — самый близкий аналог по поиску. На наших русских TikTok он нашёл «акнекутан» (23 фрагмента в 4 роликах), хотя распознавание записало «к накутана». Разобраны 8 экранов: поиск до запроса, выдача, транскрипт фрагмента, панель ролика со всеми совпадениями, Analyze (хештеги и темы), Segment, Embed (карта), коллекция.

| Фишка Twelve Labs | Как у нас | Задачи | Когда |
|---|---|---|---|
| Поиск по фрагментам с таймкодами, группировка «N совпадений в M роликах» | фрагменты по фразам ASR и сменам сцены | MEM-31, MEM-38 | MVP |
| Карточка: место, таймкод, кадр, лента ключевых кадров, «See Full Video» | + подсвеченная фраза, «Открыть в TikTok» | MEM-43 | MVP |
| Visual / Audio / Transcription | ищем везде сразу, значок источника на карточке | MEM-30, MEM-58, MEM-87 | речь — MVP, кадр/текст — после |
| Lexical + Semantic | полнотекстовый поиск + векторы, объединение рангов; триграммы против ошибок ASR | MEM-80, MEM-38 | MVP |
| Панель ролика «8 matches» | панель (десктоп) / шторка (телефон), переход к секунде | MEM-43 | MVP |
| Транскрипт фрагмента по кнопке | так же | MEM-43 | MVP |
| 👍 / 👎 на результате | разметка для Recall@10 и подбора параметров | MEM-39, MEM-41 | MVP |
| Analyze: хештеги и темы на русском | описания и теги (Kimi), тоже ищутся | MEM-47, MEM-48 | после MVP |
| Segment | только идея: заголовок фрагмента и таймлайн | — | опционально |
| Поиск по картинке-запросу | загрузить скриншот → найти ролик | MEM-87 | после MVP |
| Embed: карта коллекции | карта роликов, цвет = тема BERTopic | — | опционально, для защиты |
| Действия при наведении в коллекции | «найти похожие», «описание» | — | опционально |

Не берём: индексы, ID, operator, group_by, JSON, выбор модели, токены, анкету.

> **Уточнение 10.10 (решение 11):** из Twelve Labs берём поиск по фрагментам *внутри*, но выдача — ролики целиком: одна карточка на ролик и строка «почему найден» (источник + цитата). Ленту кадров, таймкоды фрагментов, панель «N совпадений» и окно «транскрипт фрагмента» не делаем; в карточке ролика совпадения подсвечены в транскрипте.
